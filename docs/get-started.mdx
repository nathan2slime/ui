# @nathan3boss/ui

Composable React components for forms, navigation, feedback, and content surfaces.

## Installation

```bash
pnpm add @nathan3boss/ui react react-dom styled-components
```

`styled-components` is a peer dependency. The root export provides the theme utilities `ThemeProvider`, `theme`, and `GlobalStyles` for application setup. `ThemeProvider` uses the library default theme when its `theme` prop is omitted:

```tsx
import { GlobalStyles, ThemeProvider } from '@nathan3boss/ui';

<ThemeProvider>
  <GlobalStyles />
  {/* Your application */}
</ThemeProvider>;
```

Pass `theme={theme}` or a compatible custom theme when an override is needed.

## Quick Start

```tsx preview
import React from 'react';
import { Button } from '@nathan3boss/ui/button';
import { ExampleFrame } from '@docs-support/example-frame';

export default () => {
  return (
    <ExampleFrame>
      <Button>Open workspace</Button>
    </ExampleFrame>
  );
};
```

## What is included

- Form controls: `Select`
- Actions: `Button`
- Theming: `ThemeProvider`, `theme`, and `GlobalStyles`

## Import patterns

Import each component from its public subpath export:

```tsx
import { Button } from '@nathan3boss/ui/button';
import { Select } from '@nathan3boss/ui/select';
```

Components use their public subpath exports, while theme utilities are available from the root export:

```tsx
import { Button } from '@nathan3boss/ui/button';
import { Select } from '@nathan3boss/ui/select';
```
