# Overview

`@nathan3boss/ui` is a React component library with practical action and form
controls plus a default color system that works out of the box.

## Start Here

- New to the library: go to [Get Started](/get-started.html) for installation and import patterns.
- Building forms: start with [Select](/components/select.html).
- Building actions: see [Button](/components/button.html).
- Configuring application-level tokens: see [Theme](/components/theme.html).
- Importing the library: use the subpath exports documented in [Get Started](/get-started.html).

## What You Get

- Accessible primitives built on native HTML semantics where possible.
- Composition-friendly APIs instead of large all-in-one components.
- Semantic token styling with a warm default palette and app-level CSS variable overrides.
- ESM-first package exports for modern React environments.
- Generated API references for components and public types.

## Recommended Reading Path

1. [Get Started](/get-started.html)
2. [Button](/components/button.html)
3. [Select](/components/select.html) and [Theme](/components/theme.html)

## Public Exports

- Actions: `@nathan3boss/ui/button`
- Forms: `@nathan3boss/ui/select`
- Theming: `@nathan3boss/ui` and `@nathan3boss/ui/theme`

## API Reference

Generated API docs are available under [/api](/api.html) and on each component
page. They cover the published package exports and public component contracts.
