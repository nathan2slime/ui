# Overview

`@nathan3boss/ui` is a React component library for building practical product
interfaces with less glue code. It gives you accessible controls, predictable
composition patterns, and a warm default theme that can be customized through
CSS variables.

## Start Here

- New to the library: install it and wire the theme in [Get Started](/get-started.html).
- Building actions: start with [Button](/components/button.html).
- Building forms: combine [Input](/components/input.html), [Select](/components/select.html), [Checkbox](/components/checkbox.html), [RadioGroup](/components/radio-group.html), and [Switch](/components/switch.html).
- Adding interaction layers: use [Popover](/components/popover.html), [Tabs](/components/tabs.html), [Toast](/components/toast.html), and [ScrollArea](/components/scroll-area.html).
- Customizing the visual language: configure app-level tokens in [Theme](/components/theme.html).

## What You Get

- Accessible primitives that lean on native HTML semantics and Zag state machines where they add real interaction value.
- Composition-friendly APIs that keep labels, triggers, controls, items, and content explicit.
- Semantic token styling with a warm default palette, clear interaction states, and app-level CSS variable overrides.
- ESM-first package exports for modern React environments, with tree-shakeable subpaths for each component.
- Live examples and generated API references for components, hooks, stores, and public types.

- Forms: `@nathan3boss/ui/input`, `@nathan3boss/ui/select`, `@nathan3boss/ui/checkbox`, `@nathan3boss/ui/radio-group`, and `@nathan3boss/ui/switch`
- Surfaces and feedback: `@nathan3boss/ui/popover`, `@nathan3boss/ui/scroll-area`, `@nathan3boss/ui/tabs`, and `@nathan3boss/ui/toast`
- Theming: `@nathan3boss/ui` and `@nathan3boss/ui/theme`
