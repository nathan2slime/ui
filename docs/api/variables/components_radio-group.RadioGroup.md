# Variable: RadioGroup

> `const` **RadioGroup**: `ForwardRefExoticComponent`\<`Omit`\<`RadioGroupProps`, `"id"`\> & `object` & `RefAttributes`\<`HTMLDivElement`\>\>

Renders a Zag-backed radio group from a typed item collection.

## Example

```tsx
<RadioGroup label="Fruits" items={[{ value: 'apple', label: 'Apples' }]} />
```
