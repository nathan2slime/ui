# Input

The `Input` component wraps a native `<input>` with the library's playful tactile styling, accessible labeling, and helper or error messaging.

## Usage

Use `label` for the visible field name and pass any native input props directly to the component.

```jsx preview
import React from 'react';
import { Input } from '@nathan3boss/ui/input';
import { ExampleFrame } from '@docs-support/example-frame';

export default () => {
  return (
    <ExampleFrame width="320px">
      <Input
        helperText="Choose the name shown in your cute profile."
        label="Nickname"
        placeholder="Akasa"
      />
    </ExampleFrame>
  );
};
```

## Sizes

Use `size` to adjust the field height and text scale.

```jsx preview
import React from 'react';
import { Input } from '@nathan3boss/ui/input';
import { ExampleFrame } from '@docs-support/example-frame';

export default () => (
  <ExampleFrame width="320px">
    <Input label="Small" placeholder="sm" size="sm" />
    <br />
    <Input label="Medium" placeholder="md" size="md" />
    <br />
    <Input label="Large" placeholder="lg" size="lg" />
  </ExampleFrame>
);
```

## Variants

Use `border` when the input should visually match the Select trigger's tactile bordered surface.

```jsx preview
import React from 'react';
import { Input } from '@nathan3boss/ui/input';
import { ExampleFrame } from '@docs-support/example-frame';

export default () => (
  <ExampleFrame width="320px">
    <Input
      helperText="Matches the Select control treatment."
      label="Search"
      placeholder="Find a spell"
      variant="border"
    />
  </ExampleFrame>
);
```

## Helper and error text

`helperText` is connected with `aria-describedby`. When `errorText` is present, it replaces the helper message and marks the input invalid.

```jsx preview
import React from 'react';
import { Input } from '@nathan3boss/ui/input';
import { ExampleFrame } from '@docs-support/example-frame';

export default () => (
  <ExampleFrame width="320px">
    <Input
      color="danger"
      errorText="Email is required before sending."
      label="Email"
      placeholder="you@example.com"
    />
  </ExampleFrame>
);
```

## Full width

Set `fullWidth` when the field should stretch to its container.

```jsx preview
import React from 'react';
import { Input } from '@nathan3boss/ui/input';
import { ExampleFrame } from '@docs-support/example-frame';

export default () => (
  <ExampleFrame width="360px">
    <Input fullWidth label="Search" placeholder="Find a spell" />
  </ExampleFrame>
);
```
