# Card

The `Card` component is a lightweight surface for grouping arbitrary content. It keeps the styling opinionated and leaves the internal layout up to you.

## Usage

```jsx preview
import React from 'react';
import { Card } from '@nathan3boss/ui/card';
import { ExampleFrame, ExampleSurface } from '@docs-support/example-frame';

export default () => {
  return (
    <ExampleFrame width="420px">
      <Card interactive>
        <div style={{ display: 'grid', gap: '16px' }}>
          <ExampleSurface minHeight="180px" radius="10px" surface="soft" />
          <div style={{ display: 'grid', gap: '8px' }}>
            <span>Recommended Log</span>
            <h3 style={{ margin: 0 }}>Journey of Reflection</h3>
          </div>
          <p style={{ color: 'rgba(45, 54, 82, 0.82)', margin: 0 }}>
            A deep dive into the 10-year journey of the hero party and the weight of time.
          </p>
        </div>
      </Card>
    </ExampleFrame>
  );
};
```

## Horizontal Layout

Build denser horizontal cards by composing your own inner layout inside the surface.

```jsx preview
import React from 'react';
import { Card } from '@nathan3boss/ui/card';
import { ExampleFrame, ExampleSurface } from '@docs-support/example-frame';

export default () => {
  return (
    <ExampleFrame width="560px">
      <Card interactive>
        <div
          style={{
            alignItems: 'stretch',
            display: 'grid',
            gap: '24px',
            gridTemplateColumns: '180px minmax(0, 1fr)',
          }}
        >
          <ExampleSurface minHeight="100%" minWidth="180px" radius="10px" surface="subtle" />
          <div style={{ display: 'grid', gap: '12px' }}>
            <h4 style={{ margin: 0 }}>Spellbook: Vol 12</h4>
            <p style={{ color: 'rgba(45, 54, 82, 0.82)', margin: 0 }}>
              A collection of minor folk magic spells from the Central Lands.
            </p>
          </div>
        </div>
      </Card>
    </ExampleFrame>
  );
};
```

## Accent Tone

Use `tone="accent"` for promotional or highlight surfaces that need stronger emphasis.

```jsx preview
import React from 'react';
import { Button } from '@nathan3boss/ui/button';
import { Card } from '@nathan3boss/ui/card';
import { ExampleFrame } from '@docs-support/example-frame';

export default () => {
  return (
    <ExampleFrame width="420px">
      <Card interactive tone="accent">
        <div style={{ display: 'grid', gap: '16px' }}>
          <div
            style={{
              alignItems: 'center',
              display: 'flex',
              gap: '12px',
              justifyContent: 'space-between',
            }}
          >
            <h3 style={{ margin: 0 }}>The Aureole Expedition</h3>
            <span>Seasonal Update</span>
          </div>
          <p style={{ color: 'rgba(255, 250, 245, 0.92)', margin: 0 }}>
            "It is a place where one can speak with the spirits of the dead."
          </p>
          <div
            style={{
              alignItems: 'center',
              borderTop: '1px solid rgba(255, 250, 245, 0.28)',
              display: 'flex',
              gap: '16px',
              justifyContent: 'space-between',
              paddingTop: '20px',
            }}
          >
            <span>Expedition log</span>
            <Button color="default" variant="outline">Join Log</Button>
          </div>
        </div>
      </Card>
    </ExampleFrame>
  );
};
```
