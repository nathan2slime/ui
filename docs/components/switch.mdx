# Switch

`Switch` is an accessible Zag-backed toggle for boolean settings. It renders a
hidden checkbox for form integration, a visual control, a thumb, and a connected
label.

## Basic Usage

Pass `label` for a stable visible label. Use `defaultChecked` for uncontrolled
initial state.

```jsx preview
import React from 'react';
import { Switch } from '@nathan3boss/ui/switch';
import { ExampleFrame } from '@docs-support/example-frame';

export default () => (
  <ExampleFrame width="320px">
    <Switch label="Enable moonlight mode" defaultChecked />
  </ExampleFrame>
);
```

## Dynamic On And Off Text

When no `label` or children are provided, the component mirrors Zag's example
and renders `checkedLabel` or `uncheckedLabel` based on the current checked
state. The defaults are `On` and `Off`.

```jsx preview
import React from 'react';
import { Switch } from '@nathan3boss/ui/switch';
import { ExampleFrame } from '@docs-support/example-frame';

export default () => (
  <ExampleFrame width="220px">
    <Switch checkedLabel="On" uncheckedLabel="Off" />
  </ExampleFrame>
);
```

## Controlled State

Use `checked` with `onCheckedChange` when the parent owns the state. The callback
receives Zag's `{ checked }` details object.

```tsx
const [checked, setChecked] = useState(false);

<Switch
  checked={checked}
  label="Receive alerts"
  onCheckedChange={({ checked }) => setChecked(checked)}
/>;
```

## Appearance

Use `color` with `default`, `success`, `warning`, or `danger`, and `size` with
`sm`, `md`, or `lg`. `labelPlacement="start"` moves the label before the visual
control.

```jsx preview
import React from 'react';
import { Switch } from '@nathan3boss/ui/switch';
import { ExampleFrame } from '@docs-support/example-frame';

export default () => (
  <ExampleFrame width="320px">
    <Switch
      color="success"
      defaultChecked
      label="Auto-save spells"
      labelPlacement="start"
      size="lg"
    />
  </ExampleFrame>
);
```
