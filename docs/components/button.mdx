# Button

The `Button` component provides a playful kawaii action control with styled-components-based styling and a small set of ergonomic variants.

## Usage

Use `children` for the label content and choose a variant that matches the emphasis of the action.

```jsx preview
import React from 'react';
import { Button } from '@nathan3boss/ui/button';
import { ExampleFrame } from '@docs-support/example-frame';

export default () => {
  return (
    <ExampleFrame>
      <Button>Send gift</Button>
    </ExampleFrame>
  );
};
```

## Variants

Use `solid` for primary game actions, `outline` for secondary actions, `border` for Select-like tactile controls, and `ghost` for low-emphasis actions.

```jsx preview
import React from 'react';
import { Button } from '@nathan3boss/ui/button';
import { ExampleFrame } from '@docs-support/example-frame';

export default () => {
  return (
    <ExampleFrame direction="row" gap="12px" wrap>
      <Button variant="solid">Send gift</Button>
      <Button variant="outline">View all</Button>
      <Button variant="border">Choose path</Button>
      <Button variant="ghost">Friend zone</Button>
    </ExampleFrame>
  );
};
```

## Sizes

The button supports compact, default, and large sizing through the `size` prop.

```jsx preview
import React from 'react';
import { Button } from '@nathan3boss/ui/button';
import { ExampleFrame } from '@docs-support/example-frame';

export default () => {
  return (
    <ExampleFrame align="center" direction="row" gap="12px" wrap>
      <Button size="sm">Invite</Button>
      <Button size="md">Accept</Button>
      <Button size="lg">Send gift</Button>
    </ExampleFrame>
  );
};
```

## Full Width

Enable `fullWidth` when the button should stretch to match the container width.

```jsx preview
import React from 'react';
import { Button } from '@nathan3boss/ui/button';
import { ExampleFrame } from '@docs-support/example-frame';

export default () => {
  return (
    <ExampleFrame width="320px">
      <Button fullWidth>Accept request</Button>
    </ExampleFrame>
  );
};
```

## Busy and disabled states

Use the native `disabled` prop when an action cannot be used. During an async
operation, add `aria-busy="true"` so the control communicates that it is
processing while keeping its label visible.

```jsx preview
import React from 'react';
import { Button } from '@nathan3boss/ui/button';
import { ExampleFrame } from '@docs-support/example-frame';

export default () => (
  <ExampleFrame direction="row" gap="12px" wrap>
    <Button disabled>Already sent</Button>
    <Button aria-busy="true">Sending gift…</Button>
  </ExampleFrame>
);
```

## Theme customization

Button colors come from the immutable `theme` palette. Wrap the component with `ThemeProvider` to provide a custom palette while keeping the same Button API.

```jsx preview
import React from 'react';
import { Button } from '@nathan3boss/ui/button';
import { ThemeProvider, theme } from '@nathan3boss/ui';
import { ExampleFrame } from '@docs-support/example-frame';

const customTheme = {
  ...theme,
  colorPalettes: {
    ...theme.colorPalettes,
    default: {
      ...theme.colorPalettes.default,
      solid: {
        ...theme.colorPalettes.default.solid,
        background: '#ff73c6',
        backgroundActive: '#d93b8e',
        backgroundHover: '#ff9ade',
        border: '#d93b8e',
        borderHover: '#bd2f79',
      },
    },
  },
};

export default () => {
  return (
    <ExampleFrame
      align="center"
    >
      <ThemeProvider theme={customTheme}>
        <Button>Cute boost</Button>
      </ThemeProvider>
    </ExampleFrame>
  );
};
```

The root export also provides `GlobalStyles` and `theme` for application-level setup.
